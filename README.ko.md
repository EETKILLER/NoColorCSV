# NoColorCSV

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md)

NoColorCSV는 색각 장애가 있거나 색상만으로 열을 구분하기 어려운 사용자를 위한 VS Code CSV 읽기 확장입니다. 열 번호, 헤더, 셀 내용 미리 보기와 키보드 탐색으로 텍스트 데이터의 위치를 파악할 수 있습니다.

## VS Code 실행 화면

다음 화면은 [예제 파일](examples/sample.csv)을 사용한 v0.1.3 상태 표시줄입니다. 현재 상태 표시줄에는 논리 행 번호도 표시됩니다. 새 화면 캡처는 준비 중입니다.

**현재 열:** 커서가 `hello, world`에 있으면 상태 표시줄에 3열과 `note` 헤더가 표시됩니다.

![VS Code에서 커서가 3열에 있고 확대 상자에 상태 표시줄의 CSV: column 3 of 3 · note가 표시된 화면](docs/images/column-status.png)

**셀 상세 정보:** 커서가 `London, UK`에 있을 때 상태 표시줄 항목을 선택하면 행 번호, 열 번호, 헤더, 셀 값이 텍스트로 표시됩니다. 따옴표 안의 쉼표는 구분자로 처리되지 않습니다.

![VS Code에서 2열의 London, UK 셀 상세 정보를 표시하고 확대 상자에 상태 표시줄의 CSV: column 2 of 3 · city가 표시된 화면](docs/images/cell-details.png)

## Rainbow CSV와의 차이

[Rainbow CSV](https://github.com/mechatroner/vscode_rainbow_csv)는 열을 서로 다른 색으로 강조하며 상태 표시줄과 마우스 올리기 정보, 열 정렬, 쿼리 등도 제공합니다. NoColorCSV는 열 색상을 구분하지 않고 CSV를 읽는 작업에 초점을 맞춥니다.

| | NoColorCSV | Rainbow CSV |
| --- | --- | --- |
| 열 식별 | 열 번호, 헤더, 셀 미리 보기를 텍스트로 표시 | 색상 강조와 상태 표시줄 및 마우스 올리기 정보 |
| 키보드 작업 | 인접한 열 또는 같은 열의 다른 행으로 이동 | 열 추적과 다중 커서 편집 등 |
| 파일 형식 | 쉼표로 구분된 `.csv` | CSV, TSV 및 기타 구분 형식 |
| 데이터 도구 | 셀 읽기와 위치 확인 | 정렬, CSVLint, RBQL 쿼리 등 |

NoColorCSV는 CSV 내용을 수정하거나 열에 색상을 추가하지 않습니다.

## 설치

[최신 릴리스](https://github.com/EETKILLER/NoColorCSV/releases/latest)에서 `.vsix` 파일을 다운로드합니다. VS Code의 **확장** 보기에서 `…` → **VSIX에서 설치...**를 선택하고 다운로드한 파일을 지정합니다.

## 사용 방법

`.csv` 파일을 열고 커서를 이동하면 상태 표시줄에 논리 행 번호, 현재 열 번호, 해당 행의 열 수, 사용 가능한 헤더가 표시됩니다. 빈 셀과 없는 헤더도 텍스트로 표시합니다. 비어 있지 않은 현재 셀에는 실선 밑줄과 가장자리 표시가, 화면에 보이는 같은 열의 비어 있지 않은 셀에는 점선 밑줄과 다른 표시가 나타납니다. 빈 셀에는 가장자리 표시만 나타납니다. 상태 표시줄 항목에서 셀 정보를 텍스트로 확인하거나 명령 팔레트를 사용할 수 있습니다.

| 명령 | Windows / Linux | macOS |
| --- | --- | --- |
| NoColorCSV: 현재 열 정보 표시 | — | — |
| NoColorCSV: 다음 열로 이동 | Ctrl+Alt+Shift+→ | Cmd+Alt+Shift+→ |
| NoColorCSV: 이전 열로 이동 | Ctrl+Alt+Shift+← | Cmd+Alt+Shift+← |
| NoColorCSV: 같은 열의 다음 행으로 이동 | Ctrl+Alt+Shift+↓ | Cmd+Alt+Shift+↓ |
| NoColorCSV: 같은 열의 이전 행으로 이동 | Ctrl+Alt+Shift+↑ | Cmd+Alt+Shift+↑ |

단축키는 VS Code의 **바로 가기 키**에서 `NoColorCSV`를 검색해 변경할 수 있습니다. 행 이동은 대상 열이 없는 행을 건너뜁니다.

`nocolorcsv.hasHeader` 설정은 기본적으로 첫 번째 CSV 레코드를 헤더로 사용합니다. 헤더가 없는 파일에서는 이 설정을 끄세요. 행 번호는 항상 첫 번째 레코드부터 계산합니다.

`nocolorcsv.columnFocus`의 기본값은 `column`입니다. `cell`은 현재 셀만 표시하고 `off`는 표시를 끕니다. `nocolorcsv.statusBar`의 기본값은 `true`이며 끄면 상태 표시줄 항목이 숨겨집니다. 표시를 꺼도 **현재 열 정보 표시** 명령과 키보드 탐색은 계속 작동합니다. 빈 파일에는 커서 위치가 하나 있으며 마지막 줄바꿈은 논리 행을 추가하지 않습니다.

`nocolorcsv.columnSymbols`는 기본적으로 꺼져 있습니다. 켜면 현재 셀의 가장자리와 상태 표시줄에 1부터 시작하는 열 번호와 반복 기호가 함께 표시됩니다. 8개 기호를 순환하므로 1열과 9열은 모양이 같아도 번호로 구별할 수 있습니다. 같은 열의 다른 셀은 간단한 표시를 유지합니다. 글꼴에 기호가 없으면 상태 표시줄이나 **현재 열 정보 표시**의 열 번호를 확인하세요.

`nocolorcsv.accessibilityPreset`은 `standard`(v0.2 표시), `highContrast`(더 굵은 포커스 테두리, 기호, 텍스트 안내), `screenReader`(기본적으로 포커스 표시와 기호를 끄고 행·열·헤더·값을 텍스트로 유지)를 제공합니다. 이 확장의 표시만 변경합니다. 명시적으로 지정한 `columnFocus`, `statusBar`, `columnSymbols`는 프리셋 기본값보다 우선합니다. 프리셋 기본값으로 돌아가려면 사용자 또는 작업 영역 설정에서 해당 개별 설정을 삭제하세요.

따옴표로 묶인 필드, 필드 안의 쉼표와 줄바꿈, 이중 따옴표 이스케이프, UTF-8 BOM을 처리합니다. 구분자는 반각 쉼표 `,`이며 전각 쉼표 `，`는 일반 텍스트로 취급합니다.

### 읽기 전용 표 미리보기

`.csv` 텍스트 편집기에서 명령 팔레트의 **NoColorCSV: 읽기 전용 표 미리보기 열기**를 실행하세요. 별도 탭에 저장하지 않은 변경을 포함한 현재 편집기 내용이 표시됩니다. 같은 파일에서 다시 실행하면 탭을 재사용합니다. 미리보기는 CSV를 편집하거나 저장하지 않습니다. `nocolorcsv.hasHeader`로 첫 레코드를 헤더로 사용해도 해당 레코드는 논리적 1행입니다.

Tab으로 표에 들어가 방향키로 셀을 이동하세요. Home/End는 행의 첫/마지막 열로, Page Up/Page Down은 50행 단위의 페이지로 이동합니다. Enter 또는 “원본의 이 셀로 이동”으로 원본 커서를 이동합니다. 빈 필드는 “비어 있음”, 짧은 행은 “이 열 없음”으로 표시됩니다. 잘못된 필드와 열 개수 차이는 문자로 알려주며, “문제 표시”에서 VS Code 문제 패널을 열 수 있습니다. 긴 값은 화면에서 줄여 보이지만 스크린 리더로 전체를 읽을 수 있습니다. Ctrl+W(macOS에서는 Cmd+W)로 미리보기 탭을 닫고 원본으로 돌아갑니다. 원본을 닫거나 이름을 바꾸면 사용할 수 없다는 안내가 나타납니다.

큰 파일은 확장 호스트에서 해석하며 한 번에 50행만 표시합니다. 매우 큰 CSV는 처음 여는 데 시간이 걸릴 수 있습니다. 셀 안의 링크와 HTML은 문자 그대로 표시됩니다.

수동 확인: F5로 확장 개발 호스트를 열고 `examples/sample.csv`의 미리보기에서 키보드로 이동합니다. 셀을 저장하지 않고 수정한 뒤 `nocolorcsv.hasHeader`를 바꾸어 행, 헤더, 저장하지 않음 표시를 확인하세요. 빈 필드, 짧은 행, 따옴표 안 줄바꿈, 고대비 테마, 200% 확대를 확인하고 미리보기 동작으로 원본 파일과 변경 상태가 바뀌지 않는지 확인합니다.

### CSV 검사

`nocolorcsv.validation.enabled`는 기본적으로 켜져 있습니다. **문제** 패널에는 닫히지 않은 따옴표, 닫는 따옴표 뒤의 문자, 따옴표로 감싸지 않은 필드의 큰따옴표, 열 개수 불일치가 표시됩니다. 헤더가 있으면 첫 레코드, 없으면 첫 번째 비어 있지 않은 논리 레코드의 열 개수를 기준으로 합니다. 끝의 줄바꿈은 레코드를 추가하지 않습니다. 진단은 읽기 전용이며 편집 후 갱신되고 CSV에서 전환하거나 파일을 닫거나 검사를 끄면 지워집니다. 처음 200개 문제를 표시하고 추가 문제가 있으면 텍스트로 알립니다.

이동은 선택 영역의 활성 끝에서 시작하고 여러 커서를 하나로 합칩니다. 형식이 잘못된 필드에서는 이동을 시작하거나 그 필드로 이동할 수 없습니다. 경계에서는 커서를 움직이지 않고 이동에 성공할 때까지 안내를 한 번만 표시합니다. 기본 키가 충돌하면 VS Code의 **바로 가기 키**에서 `NoColorCSV`를 검색해 변경하세요. 명령 팔레트에서도 실행할 수 있습니다.

## 개발

[Visual Studio Code](https://code.visualstudio.com/)와 Node.js 24가 필요합니다.

```sh
npm ci
npm test
```

VS Code에서 저장소를 열고 **F5**를 누르면 확장 개발 호스트가 실행됩니다. 실행 전에 TypeScript를 컴파일합니다. `examples/sample.csv`에서 따옴표 안의 쉼표를 지나 커서를 움직이며 표시와 논리 행 번호를 확인하세요. `nocolorcsv.columnFocus`를 `column`, `cell`, `off`로 바꾸고 `nocolorcsv.statusBar`를 끈 뒤 **현재 열 정보 표시**를 실행하세요. 빈 셀, 따옴표 안의 줄바꿈, 스크롤, CSV가 아닌 파일로 전환도 확인하고 확대 화면과 고대비 테마에서도 살펴보세요. 이 작업으로 CSV 파일이 변경되거나 저장되지 않아야 합니다.

v0.3 검증에는 20열 이상의 임시 CSV를 만들고 1, 9, 17열의 기호는 반복되지만 번호는 다름을 확인하세요. 설정에서 기호와 세 프리셋을 전환하고 `highContrast`에서 `columnSymbols`를 명시적으로 꺼 보세요. 좁은 편집기, 자동 줄바꿈, 200% 확대, 밝은/어두운/고대비 테마, 스크린 리더의 상태 표시줄 및 **현재 열 정보 표시** 읽기를 확인하세요. 가능한 Windows, macOS, Linux에서 키보드 탐색도 확인하세요. CSV를 닫거나 다른 형식의 탭으로 전환하면 표시가 사라져야 합니다. 전후 파일 내용을 비교하여 확장이 편집하지 않았는지 확인하세요.

설치 가능한 VSIX를 만들려면 다음을 실행합니다.

```sh
npm run package
```
