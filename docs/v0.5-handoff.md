# v0.5.0 发布交接

更新日期：2026-10-15。v0.5.0 以 v0.4 的统一解析和诊断为基础，提供独立只读 CSV 表格预览。工作区原有的 `docs/development/` 是未跟踪开发规格，未纳入本次提交。

## 交付范围

- **05-1**：`src/preview.ts` 将逻辑记录、解码值、UTF-16 字段偏移和诊断映射为预览页。首行可作为表头，但仍是第 1 条逻辑记录。空文件无数据行；空字段与短行缺列分别标注。
- **05-2**：命令 `nocolorcsv.openPreview` 从活动 `.csv` 文本编辑器打开独立 WebviewPanel。同一文档复用面板，文档间相互独立。编辑后 150 ms 更新，并用文档版本校验消息；源文档关闭或重命名后显示不可用状态。面板关闭和扩展释放时清理监听器。
- **05-3 / 05-4**：Webview 用语义化表格，每页仅渲染 50 行。方向键、Home/End、PageUp/PageDown、Enter 可导航和跳回原文；焦点、行列标题、空值及错误都有文字。长值仅在视觉上截断。CSV 文本通过 `textContent` 插入；CSP 禁止外部连接，脚本以 nonce 加载，资源根限定为 `webview/`。消息类型和数字参数在扩展端校验。
- **05-5**：命令清单、五种 README、命令本地化与四种运行时翻译已同步。`package.json` 与 `package-lock.json` 均为 `0.5.0`，无新增产品依赖。

预览不调用源文档编辑、保存或写回 API，默认编辑器仍是原始文本。只解析以半角逗号分隔的 `.csv`。

## VS Code 开发宿主检查

在 Windows 的 VS Code 1.142 开发宿主中：

1. `examples/sample.csv` 通过命令面板打开预览，显示 5 条逻辑记录。方向键可移动焦点。ARIA 快照包含行标题、列标题和完整单元格值。
2. 在临时 CSV 中放入 `<script>alert(1)</script>`、`<img onerror=alert(1)>`、`&amp;` 和 URL；预览显示字面文本，表格中没有由字段生成的 `img` 或 `a` 元素。
3. 100,001 条记录的临时 CSV 打开后，表格 DOM 为 50 行。PageDown 到下一页后跳回原文第 51 行；原文未保存编辑后，预览出现未保存提示和新值，磁盘文件仍保持原内容。
4. 在高对比度主题和约 200% 缩放下检查了可见焦点及分页。打开、滚动、关闭预览未改变 `examples/sample.csv` 的文件内容。

以下人工检查尚未完成：真人屏幕阅读器朗读、macOS/Linux 的实际界面操作。ARIA 快照和 Windows 键盘检查不能代替这些结果。大文件首次打开仍需在扩展宿主中整篇解析；分页限制的是 Webview 行数，并非解析内存。

在 VS Code 中按 **F5** 启动扩展开发宿主，打开 `examples/sample.csv`，通过命令面板运行 **NoColorCSV: Open Read-only Table Preview**。只用键盘检查 Tab、方向键、Home/End、PageUp/PageDown、Enter 和 Ctrl+W（macOS 为 Cmd+W）。再切换 `nocolorcsv.hasHeader`、编辑但不保存一个临时 CSV、检查“问题”面板与预览文字。使用屏幕阅读器朗读行列标题、完整长值和错误；在 Windows/macOS/Linux 可用环境中记录主题、缩放和按键差异。预览操作前后比较文件字节及 dirty 状态。
